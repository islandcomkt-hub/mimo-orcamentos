# Mimo Orçamentos Android

Aplicativo Android WebView offline que empacota a plataforma de orçamentos da Mimo de Festa.

## APK
No GitHub, execute Actions > Build APK > Run workflow. O arquivo será gerado como artifact `Mimo-Orcamentos-APK`.

## Conteúdo web
`app/src/main/assets/index.html`

## Pacote
